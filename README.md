# Mi proyecto de aprendizaje Git y GitHub

## Presentación personal

Soy aprendiz del SENA del programa Tecnólogo en Análisis y Desarrollo de Software (ADSO).

Me interesa el desarrollo de software, la programación y la creación de soluciones tecnológicas.

Actualmente estoy fortaleciendo mis conocimientos en HTML, CSS, Python, Java, SQL, Git y GitHub.

## Objetivos

- Aprender a utilizar Git y GitHub.
- Comprender el control de versiones.
- Practicar comandos de Git.
- Desarrollar proyectos de programación.
- Construir un portafolio profesional.
- Fortalecer mis habilidades como desarrollador de software.

## Contenido del repositorio

### Ejercicios
Contiene tres ejercicios prácticos sobre presentación personal, comandos Git y Markdown.

### Proyectos
Contiene una calculadora básica desarrollada con HTML, CSS y JavaScript.

### Evidencias
Contiene los registros y evidencias de las actividades realizadas.

## Ruta de aprendizaje de 15 días

| Día | Actividad |
|---|---|
| 1 | Crear cuenta GitHub |
| 2 | Instalar Git |
| 3 | Configurar Git |
| 4 | Crear repositorio |
| 5 | Clonar repositorio |
| 6 | Realizar commits |
| 7 | Practicar Push y Pull |
| 8 | Aprender Markdown |
| 9 | Crear README profesional |
| 10 | Crear ramas |
| 11 | Practicar Merge |
| 12 | Realizar Pull Requests |
| 13 | Desarrollar proyecto personal |
| 14 | Publicar proyecto |
| 15 | Construir portafolio |

## Buenas prácticas

- Realizar commits frecuentes.
- Utilizar mensajes claros.
- Mantener actualizado el README.
- Organizar las carpetas.
- No publicar contraseñas ni información sensible.
- Practicar diariamente.

## Conclusión

Este repositorio representa mi proceso de aprendizaje en Git y GitHub durante mi formación en ADSO del SENA. Mi propósito es continuar desarrollando mis habilidades y construir proyectos que demuestren mis conocimientos.
